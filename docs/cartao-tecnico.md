## Segurança

- Sem chaves/API secrets no frontend.
- Nenhum backend; nenhum banco ou autenticação.
- Links externos usam `rel="noopener noreferrer"` e `target="_blank"`.
- Dados do formulário são descartados; não trafegam para servidores.
- Evitar dados pessoais reais e fotografias de pessoas sem autorização.
- Conferir a URL pública pelo navegador, validar HTTPS e ausência de conteúdo misto após publicar.

## Guia para completar após o deploy

1. Conferir o link GitHub e a URL do GitHub Pages após o primeiro deploy.
2. Conferir nome do domínio, gestão do DNS e HTTPS pelo cadeado/inspeção do certificado.
3. Registrar em `testes.md` os resultados e capturas reais.
4. Revisar se todos os textos sobre o evento permanecem identificados como fictícios.
