# Wireframe simplificado

```text
┌──────────────────────────────────────────────────────────────────┐
│ Faixa de aviso (projeto fictício)                                │
│ [VIVA CULTURA]  Início Sobre Programação Atrações Local Contato  │
├──────────────────────────────────────────────────────────────────┤
│ HERO                               Ilustração exclusiva          │
│ Onde a cultura encontra você       Evento cultural               │
│ [Explorar programação] [Conheça]                                │
├──────────────────────────────────────────────────────────────────┤
│ DATA                         LOCAL                        ENTRADA│
├──────────────────────────────────────────────────────────────────┤
│ SOBRE: objetivo do festival       Benefícios/ilustração         │
├──────────────────────────────────────────────────────────────────┤
│ PROGRAMAÇÃO [Sábado 14] [Domingo 15]                             │
│ 10h Abertura ...                                                  │
├──────────────────────────────────────────────────────────────────┤
│ ATRAÇÕES: [Música] [Arte e dança] [Gastronomia]                   │
├──────────────────────────────────────────────────────────────────┤
│ LOCALIZAÇÃO: endereço + link Google Maps  | mapa ilustrativo     │
├──────────────────────────────────────────────────────────────────┤
│ ACESSIBILIDADE E INFORMAÇÕES IMPORTANTES                         │
├──────────────────────────────────────────────────────────────────┤
│ CONTATO: explicação              | formulário demonstrativo     │
├──────────────────────────────────────────────────────────────────┤
│ RODAPÉ: links para seções e redes sociais de exemplo             │
└──────────────────────────────────────────────────────────────────┘
```

**No celular:** menu recolhível; hero, seções, cards e formulário em uma coluna; botões com área confortável para toque; tabela de horários convertida em lista; nenhuma rolagem horizontal esperada.
